# Matriz de configuración candidata H4 para nueve servicios

Esta matriz diferencia variables leídas por el código, valores candidatos y estado remoto. Las fuentes son parsers de `apps/<servicio>/src/` y Compose Oracle versionados en el SHA actual. No contiene secretos ni acredita configuración remota. Los nombres no encontrados en parsers se marcan como no implementados/no constatados; no agregarlos a `runtime.env` por inferencia.

## Variables candidatas pedidas

| Nombre propuesto | Resultado de comprobación | Acción operativa |
|---|---|---|
| `G6_SECURITY_MODE` | Los nueve componentes admiten `PUBLIC_READ_ONLY`, `SIMULATED_AUTH` y `G7_AUTHENTICATED` en el código de esta rama. | Fase 1 candidata: `PUBLIC_READ_ONLY`; las fases 2/3 seleccionan el mismo SHA y requieren sus issuers/JWKS y permisos respectivos. |
| Bypasses heredados de demo | Las banderas de acceso anónimo amplio de Gateway, Catalog, Taxonomy, Promotions, Pricing, Bulk e Inventory se rechazan o dejaron de conceder acceso. | No configurar flags de IP, red Docker o headers como identidad. |
| `GATEWAY_PUBLIC_OPERATION_IDS=` | Gateway lo consume y valida contra operation IDs contractuales. | Mantener vacío; Docs registra cero `PUBLICA_APROBADA`. |
| `CATALOG_PUBLIC_OPERATION_IDS=` | Catalog lo consume y restringe a un allowlist de lecturas elegibles. | Mantener vacío; ninguna operación queda pública por inferencia. |
| `TAXONOMY_PUBLIC_OPERATION_IDS=` | Taxonomy lo consume y valida contra operaciones elegibles. | Mantener vacío; ninguna operación queda pública por inferencia. |
| `AUTH_ISSUER`, `AUTH_JWKS_URL` | Gateway, Pricing, Price Audit y Promotions aceptan este par; Catalog y Taxonomy usan `SECURITY_ISSUER`, `SECURITY_DISCOVERY_URL`, `SECURITY_JWKS_URL`. | Endpoints reales G7 pendientes de provisión operativa; jamás registrar valores secretos aquí. |

## Bloqueos y estados independientes

- **G7:** AUTH/SECURITY issuer/JWKS real, identidad de servicio y permisos mínimos son configuración operativa pendiente del owner G7/Marco. No inventar URLs, scopes, grants, secretos ni roles.
- **RabbitMQ:** owner de respuesta: Marco/owner de contrato y plataforma; afecta publish/consume de servicios que habiliten AMQP. Desbloqueo verificable: homologar exchanges, colas, routing keys y ACL; autorizar conectividad privada; probar desde la red de cada servicio. Sin red nueva ni aliases inventados.
- **Catalog histórico:** `BLOCKED_CATALOG_HISTORICAL_ACTIVATION`; afecta activación de productos/precios existentes. Owners: Marco y responsables de Pricing/Inventory. Desbloqueo: acuerdos e implementaciones de Pricing/Inventory y evidencia de comprobaciones de activación. No cambiar estados SQL ni activar preview como sustituto.
- **Operaciones públicas:** owner Marco/arquitectura G6 y G7; afecta cualquier acceso anónimo. Desbloqueo: Gateway oficial con G7, bypass desactivado y probado, aprobación explícita por operación (Docs registra cero `PUBLICA_APROBADA`), pruebas JWT y aprobación separada del cambio Caddy.
- **Oracle:** no se accedió ni instaló. Despliegue, integración autenticada, homologación y readiness permanecen estados externos distintos de esta documentación.
